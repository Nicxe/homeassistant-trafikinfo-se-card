# Trafikinfo SE - Alert Card (Moved)

This repository has moved to:

https://github.com/Nicxe/homeassistant-trafikinfo-se

The alert card is now released together with the Trafikinfo SE integration in the main repository.

## New installation source
1. Open releases in `Nicxe/homeassistant-trafikinfo-se`.
2. Download `trafikinfo-se-alert-card.js`.
3. Place the file in `config/www/`.
4. Keep your Lovelace resource URL as `/local/trafikinfo-se-alert-card.js`.
